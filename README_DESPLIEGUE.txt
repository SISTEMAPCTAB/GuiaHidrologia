DESPLIEGUE RÁPIDO
1) Configura Supabase siguiendo README_CONFIGURACION.txt.
2) Edita config.js con Project URL y anon key.
3) Sube TODO el contenido de esta carpeta al directorio público del servidor.
4) Abre /index.html o simplemente la carpeta raíz.
5) La validación pública de diplomas se realiza en /verificar.html?folio=AMH-HID-2026-000001

Para Apache se incluye .htaccess. Para Nginx se incluye nginx-guia.conf.example.
